01 · 播放

展厅里按 空格 连播，1–9 / 0 跳段，H 隐藏控制栏。

02 · 换剧本

复制任意 demo_data.json 改文案，用 ?data=my_script.json 加载，12 套通用。

03 · 换肤

01–06 展厅右上角胶囊点一下即换，或加 ?theme=obsidian；剧本里写 "theme": { "preset": "…" } 也行。
